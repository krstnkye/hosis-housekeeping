# Academic documentation template profile

## Reference source

- `HOSIS_Housekeeping_Subsystem_Complete_Documentation_2026_final.docx`
- Professor review scans: `sir james .pdf`, `sir roy.pdf`, and `sir roy (2).pdf`

## Page and institutional layout

- A4 portrait pages.
- Institutional header and footer artwork from the supplied CELTECH template are preserved.
- Main content margins follow the supplied template; the separate title page uses balanced one-inch margins.
- Figure captions are centered below the figure and use the Word `Caption` style.
- Table headers repeat across pages and rows are prevented from splitting where possible.

## Typography

- Georgia is used consistently for body text, captions, tables, and headings.
- Body text uses 11 pt with 1.15 line spacing, six-point paragraph spacing, and justified alignment.
- Heading 1, Heading 2, and Heading 3 preserve the source hierarchy and are kept with the following content.
- Captions use 9 pt and centered alignment.

## Structural conventions

- Word heading styles, not manually bolded body paragraphs, define the document outline.
- Requirement, endpoint, data-dictionary, risk-control, and verification information use native Word tables.
- Questionnaire criteria use numbered items rather than bullet symbols.
- Every architecture, DFD, and workflow figure is immediately followed by a centered caption and an explanatory narrative.
- Implementation summaries use prose and tables instead of isolated bullet lists.
